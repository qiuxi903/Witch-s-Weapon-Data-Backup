# 《魔女兵器》收藏档案 · 网站说明

停服游戏《魔女兵器》（Witch's Weapon）的完整资料站。全部数据来自五个区服客户端的实际解包与官网抓取。

---

## 一、怎么打开

站点必须从**项目根目录**启动（页面通过 `../` 引用解包素材）：

```powershell
cd "G:\project\其他\game"
python -m http.server 8950
```

然后浏览器打开 <http://127.0.0.1:8950/网站/index.html>

> 直接双击 `index.html` 打开会看不到图片 —— 浏览器禁止 `file://` 协议跨目录读取素材。

## 二、主题与外观

**默认暗色**，对齐早期 PPT 的深色规范：

| | 说明 |
|---|---|
| **暗色（默认）** | 近黑 `#07080b` + 暖白 `#eae6de` + 绯红 `#d81e3f` + 金 `#c9a227` |
| **亮色** | 「亮色模式」按钮切换 —— 米白纸感 `#faf9f7` + 暗红 `#c8102e` |
| **切换位置** | 桌面在侧栏底部；移动端在顶栏右侧的圆形按钮 |
| **记忆** | 存在 `localStorage` 的 `ww-theme` 键，下次访问自动恢复 |

字体分三套：衬线（宋体系）用于标题、无衬线用于正文、等宽用于文件名与数字。

### 侧边栏可收起

桌面端侧栏底部有「收起侧边栏」按钮，收起后变成 **60px 的图标轨道**（只留 01–12 序号和迷你 LOGO），内容区自动变宽。状态存在 `ww-mini` 键。

收起状态在页面加载前由内联脚本写入 `<html data-mini="1">`，**不会出现展开→收起的闪烁**。

### 移动端

| 断点 | 行为 |
|---|---|
| ≤ 980px | 内容区收窄，网格列数减少 |
| ≤ 880px | 侧栏变为**抽屉**，从左侧滑出；顶栏出现 LOGO + 主题按钮 + 「目录」 |
| ≤ 620px | 角色卡两列，KPI 两列，其余单列；输入框字号 16px（防 iOS 自动缩放） |
| ≤ 400px | 全部单列 |

抽屉支持点遮罩关闭、`Esc` 关闭、点菜单项关闭；视口变宽时自动收起。

### 配置表：5 个区服可切换

顶部的版本标签可切换区服，**每个区服的数据是独立文件、点开才加载**，所以 `config.html` 只有 20 KB。

| 区服 | 版本 | 类型 | 表数 | 行数 |
|---|---|---|---|---|
| 怀旧服 | v128 | 社区服 | 83 | 23,944 |
| 港澳台 | v1.6.0 | 官方 | 64 | 19,343 |
| 韩服 | v1.0 | 官方 | 57 | 14,925 |
| 日服 | v2.0.0 | 官方 | 20 | 13,907 |
| 国服 | v2.0.1 | 官方 | 14 | 11,772 |

各区服表数不同，是**客户端包里实际带的配置表数量不同**造成的 —— 国服/日服的其余配置靠运行时从 CDN 下载，没有打进安装包。

**全部行都会显示**，不截断。大表（最大的是日服 `activity`，2,609 行 × 71 列 = 185,239 个单元格）用分块渐进渲染，每 500 行让出一次主线程，底部会显示渲染进度，实测约 3 秒渲染完，渲染后 JS 堆 18 MB。

#### 下载

| 想下载什么 | 怎么下 |
|---|---|
| 当前这一张表 | 表头右上角 **⤓ CSV**（行尾 CRLF、带 BOM，Excel 直接打开）或 **JSON**（含字段名，数组套对象） |
| 搜索筛选后的结果 | 先搜索，按钮会变成「⤓ CSV（筛选后 N 行）」，导出**只含匹配行** |
| 整个区服（全部表） | 版本栏右侧 **⤓ 整个区服打包下载 ZIP**，内含每张表一个 CSV + `_说明.txt` |

ZIP 是构建时生成好的静态文件（`网站/data/zip/<区服>.zip`，240–400 KB），不依赖服务器；CSV/JSON 是浏览器现场生成，所以**直接双击打开 `config.html` 也能下载**。

> **行数怎么算的**：策划表用「表头 3~6 行 + 数据」的格式，且**每条数据之间夹着一个空行**。这里只统计真正有内容的行，已剔除空行、字段名行、类型行和中文标签行。早期版本把空行也计入，得到过 131,434 这类虚高 5 倍的数字。
>
> 另外有 10 张表（如 `title`、`suit`、`instancestructure`）在客户端里**只有表头没有数据**，页面会明确标注「这张表在客户端里只有表头，没有数据」。

#### 已知差异：怀旧服数据被改过

以官方 `国服 v2.0.1` 为基准逐项对照，怀旧服有 **19 处差异，全部是把「解锁等级」改成 1**：

```
METHOD_OPEN_LEVEL_CHAPTER2~8   → 1（官方 5/15/22/25/30/33/36）
PROMOTE_UNLOCK_RANK            → 1（官方 7）
CORE_INSTANCE_MIN_LEVEL        → 1（官方 27）
ASSOCIATION_CREATE_LEVEL       → 1（官方 20）
CHAT_CAN_SEE_LEVEL             → 1（官方 15）
…（共 19 项）
```

这是社区服常见的「全解锁」改动。**除这 19 个门槛外，其余数据与官方完全一致**（副本集 158:158、关卡 1,521:1,521，ID 分布逐项吻合）。页面上已如实标注。

#### 各区服的独有内容

| 内容 | 存在于 |
|---|---|
| 主线 `3010013`~`3010016`（第 12 关之后，4 集 × 15 关） | **全部 5 个区服** |
| 挑战关 `3040083`~`3040086`（黑洞挑战，4 集 × 16 关） | **仅日服 v2.0.0** |

主线配置里 `LAST_CAMPAIGN_INSTANCE_SET = 3010012`，即官方只开放到第 12 集；`3010013`~`3010016` 是**做完但未启用**的遗留内容。

## 五、性能设计

美术页有 7,424 张图、音频页 1,828 个播放器，一次性加载会卡死浏览器。因此：

- **分类折叠**：每个分类是一个 `<details>`，**默认只有第一个展开**。
- **懒加载**：折叠块内的 `<img>` / `<audio>` / `<video>` 初始只带 `data-src`，**展开时才写入 `src`**。
  - 实测：音频页初始只加载第一个折叠块（CV 语音 1,135 个），其余 693 个保持未加载。
  - 美术页初始只加载第一个分类，其余 7,000+ 张不发起请求。
- **缩略图**：列表用 `网站/thumbs/` 下的 640px JPEG（共 7,410 张），点击才加载原图。
- **`loading="lazy"` + `decoding="async"`**：已展开的分类内部也交给浏览器延迟解码。

## 七、无障碍与兼容

- 键盘可达：图片、角色卡、按钮均可 `Tab` 聚焦，`Enter` / `空格` 触发。
- 动画渐进增强：`<html class="no-js">` + 内联脚本切换为 `js`，**无 JS 时内容依然完整可见**。
- `.rv` 滚动显现带 1.2 秒兜底定时器，即使 `IntersectionObserver` 不触发也会显示。
- KPI 数字带 `data-final` 兜底，动画失败也恢复正确数值。
- 尊重 `prefers-reduced-motion`；触屏设备去掉悬停位移。
- 打印时隐藏侧栏、顶栏、工具条、返回顶部。
- 侧栏、抽屉、灯箱均有 `aria-label` / `aria-expanded` / `aria-pressed`。

## 九、数据来源

- 客户端解包：国服 / 日服 / 台服 / 韩服 / 国际服
- 官网抓取：`witchs-weapon.net`（日服）、`witchs-weapon.com`（国际服）
- 剧情文本：AES-128 解密，密钥 `sfe023f_9fd&fwfl`
- 配置表：`assets/assetbundle/config/clientexel/*.ab` → UnityFS(LZ4) → BytesAsset 内 CSV 密文 → XOR `0xFF`
  - 长度字段有时比实际内容**少 1 字节**，会把末尾的全角字符切断，解码时需向后试几个长度
  - `assets/assetscutinfo` 之类的表末尾带 UTF-16 BOM 等二进制残渣，需剔除
- 统计口径不含重复副本与构建工具
