# 《魔女兵器》档案站 · 宝塔面板部署指南

面向 **宝塔面板（BT Panel）+ Nginx + 纯静态** 的部署流程。

---

## 〇、先看结论

| 项目 | 值 |
|---|---|
| 要上传的目录 | `G:\project\其他\game\部署\` |
| 体积 | **1,012.2 MB** |
| 文件数 | **18,451 个** |
| 是否自包含 | **是** —— 所有素材都在本站目录内的 `files/`，不再依赖 `../` |
| 服务器要求 | 任意 nginx，**PHP / 数据库都不需要** |
| 站点根目录 | 直接指向 `部署/` 里的内容（`index.html` 必须在根） |

原来的 `网站/` 目录是**归档版**（页面用 `../` 引用仓库里的原始素材），只适合本地开着 HTTP 服务看，**不要拿去部署**。`部署/` 是为上传专门生成的自包含版本。

**素材是怎么瘦下来的**（原始 22.06 GB → 1.01 GB）：

| 类型 | 原始 | 部署版 | 手段 |
|---|---|---|---|
| 图片 | 1,511.9 MB | 253.4 MB | PNG/JPG → **WebP**（质量 82），省 83% |
| 音频 | 1,208.0 MB | 162.5 MB | WAV → **Opus 64 kbps (.ogg) + MP3 96 kbps (.mp3)** 双格式，省 87% |
| 缩略图 | 165.1 MB | 108.6 MB | 640px JPEG → WebP |
| 视频 | 285.0 MB | 289.2 MB | **原样保留**（已压缩，重编码只会掉画质） |
| 已有 MP3 | 165.6 MB | 165.6 MB | 原样保留（避免有损转有损） |

音频之所以给两份：Chrome / Firefox / Edge 走 `.ogg`（体积小），Safari 不支持 Opus 时页面里的脚本会**自动退回 `.mp3`**。两份都必须在。

## 二、上传（最容易翻车的一步）

18,451 个文件不可能一个个传。**关键坑：中文文件名编码。**

> ⚠️ **不要用 Windows 自带的「压缩到 zip」**。它按 GBK 编码文件名，Linux 解压后所有中文目录名（`07_音频资源`、`06_美术素材`…）全变乱码，站点里 1 万多个素材**全部 404**。
>
> 下面三种方式都不会有这个问题。

### 方案 A：SFTP 直传（最稳，推荐）

用 **WinSCP** 或 **FileZilla**：

| 项 | 值 |
|---|---|
| 协议 | SFTP（SSH） |
| 主机 | 服务器 IP |
| 端口 | 22 |
| 用户名 | `root` |
| 密码 | 服务器 root 密码（不是面板密码，除非你改过） |

连上后，把本地 `部署` 文件夹**整个拖到** `/www/wwwroot/` 下。

- 优点：文件名原样传输，零编码风险；支持断点续传、跳过已存在文件。
- 缺点：18,451 个小文件，SFTP 逐个握手，**大约 20–60 分钟**（取决于网络延迟）。
- 建议：先传 `html / css / js / data / thumbs`（约 145 MB，几分钟），站点立刻能看，`files/` 慢慢补。

### 方案 B：本地打包 → 上传压缩包 → 宝塔解压

**仓库里已经打好一个包**（UTF-8 文件名，可直接用）：

```
G:\project\其他\game\魔女兵器档案站_部署包.zip     987.6 MB / 18,451 个条目
```

zip 内顶层目录是 `witchweapon/`，所以在 `/www/wwwroot/` 下解压后正好得到 `/www/wwwroot/witchweapon/index.html`，不会多套一层。

要自己重新打：

```powershell
cd "G:\project\其他\game"
python tools\make-archive.py
```

> 这个脚本用 Python 的 `zipfile`，非 ASCII 文件名会自动带上 **UTF-8 标志位**（general purpose bit 11），Windows 资源管理器、7-Zip、Linux `unzip`、宝塔文件管理器都能正确还原中文名。

**如果坚持用别的工具打包**，必须注意编码：

- **7-Zip**：加 `-mcu=on` 强制 UTF-8 文件名
  ```powershell
  & "C:\Program Files\7-Zip\7z.exe" a -tzip "部署.zip" ".\部署\*" -mcu=on
  ```
- **Windows 自带 tar**：按原始字节存名字，Linux 解压天然正确
  ```powershell
  tar -czf 部署.tar.gz -C 部署 .
  ```
- ❌ **Windows 资源管理器「压缩到 zip」**：GBK 编码，**不能用**。

然后：宝塔面板 → **文件** → 进入 `/www/wwwroot/` → **上传** → 上传完点**解压**。

> 宝塔文件管理器对单个上传文件有大小限制（默认约 2 GB，可在 面板设置 → 上传限制 调整）。1 GB 的包如果浏览器上传老断，就在服务器上直接拉：
> ```bash
> cd /www/wwwroot
> wget -O 站点.zip "你的临时下载地址"
> unzip 站点.zip && rm 站点.zip
> ```
> 这个 zip 带 UTF-8 标志位，`unzip` 会按 UTF-8 还原文件名，不需要额外加参数。

### 方案 C：命令行 rsync（服务器装了 rsync 时最快）

在本地 WSL / Linux 环境：

```bash
rsync -avz --progress -e ssh "部署/" root@你的服务器IP:/www/wwwroot/witchweapon/
```

支持断点续传，重传时只传改动过的文件。

## 三、宝塔建站

1. 面板 → **网站** → **添加站点**
   - **域名**：你的域名（没有域名就填服务器 IP）
   - **根目录**：`/www/wwwroot/witchweapon`
   - **FTP**：不创建
   - **数据库**：不创建
   - **PHP 版本**：**纯静态**
2. 把 `部署/` 里的**内容**放进 `/www/wwwroot/witchweapon/`
   - ✅ 正确：`/www/wwwroot/witchweapon/index.html`
   - ❌ 错误：`/www/wwwroot/witchweapon/部署/index.html`（多套一层，全站 404）
3. 面板 → 网站 → 设置 → **默认文档**：确认列表里有 `index.html`
4. 面板 → 网站 → 设置 → **伪静态**：保持「无」
5. 权限：目录 `755`、文件 `644`，属主 `www:www`
   ```bash
   chown -R www:www /www/wwwroot/witchweapon
   find /www/wwwroot/witchweapon -type d -exec chmod 755 {} \;
   find /www/wwwroot/witchweapon -type f -exec chmod 644 {} \;
   ```

> 18,451 个文件用宝塔「文件」页面浏览会非常卡，日常维护建议用 SSH 命令行。

## 四、Nginx 配置（必须改）

面板 → 网站 → 设置 → **配置文件**，在 `server { }` 里加入下面内容。

### ① 补齐 MIME 类型 —— 最重要的一条

`.webp` 和 `.ogg` 如果返回 `application/octet-stream`，会出现：图片在部分浏览器/CDN 上被当成附件、Safari 拒绝播放 `.ogg`、CDN 不做图片优化。

**先诊断**（SSH 执行）：

```bash
# 宝塔的 nginx.conf 一般在 http 层 include 了 mime.types
grep -n mime.types /www/server/nginx/conf/nginx.conf
# 看 mime.types 里有没有 webp
grep -n webp /www/server/nginx/conf/mime.types
```

**如果上面第二条没有输出**，就在站点配置的 `server { }` 里加：

```nginx
types {
    image/webp               webp;
    audio/ogg                ogg opus;
    audio/mpeg               mp3;
    video/mp4                mp4;
    video/ogg                ogv;
    application/javascript   js mjs;
    application/json         json;
    text/css                 css;
    image/svg+xml            svg svgz;
    font/woff2               woff2;
}
```

> ⚠️ `types { }` 块在 nginx 里是**按扩展名叠加**的，不会覆盖外层已有的类型，所以只写缺的那几个也安全。
> 但如果你的 `nginx.conf` **完全没有** `include mime.types;`，那 `types{}` 会让所有没列出的扩展名变成 `application/octet-stream` —— 这种情况下请改成在 `server{}` 里先写 `include mime.types;` 再写上面的块。

### ② 字符集

```nginx
charset utf-8;
```

（宝塔默认站点配置里通常已有，确认一下即可。）

### ③ 压缩 —— 只压文本

图片 / 音频 / 视频本身已经压缩过，再 gzip 是纯浪费 CPU。

```nginx
gzip on;
gzip_vary on;
gzip_comp_level 5;
gzip_min_length 1k;
gzip_buffers 16 8k;
gzip_types text/plain text/css text/xml application/javascript
           application/json image/svg+xml application/xml;
```

> `archive.html`（7.7 MB）、`art.html`（3.1 MB）、`story.html`（2.3 MB）都是**纯文本 HTML**，gzip 后能压到 1/8 左右，这一条收益很大。
>
> 如果宝塔的 nginx 编了 brotli 模块，可以再加：
> ```nginx
> brotli on;
> brotli_comp_level 5;
> brotli_types text/plain text/css application/javascript application/json image/svg+xml;
> ```

### ④ 缓存 —— 素材永不变，页面要能更新

```nginx
# 素材与缩略图：文件名带哈希/序号，内容不会变，长缓存
location ~* ^/(files|thumbs)/ {
    expires 30d;
    add_header Cache-Control "public, immutable";
    access_log off;
}

# 样式与脚本
location ~* \.(css|js)$ {
    expires 7d;
    add_header Cache-Control "public";
}

# 页面：不缓存，改了立刻生效
location ~* \.html$ {
    expires -1;
    add_header Cache-Control "no-cache";
}

# PV 视频最大 50 MB，留够上传余量
client_max_body_size 100m;
```

### ⑤（可选）防盗链

```nginx
location ~* ^/(files|thumbs)/ {
    valid_referers none blocked server_names *.你的域名;
    if ($invalid_referer) { return 403; }
    expires 30d;
    add_header Cache-Control "public, immutable";
}
```

改完保存，宝塔会自动 `nginx -t` 并 reload。

## 六、常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| **图片全部裂开** | zip 用了 GBK 文件名，中文目录乱码 | 用 tar / `7z -mcu=on` / SFTP 重传（见第二节） |
| **图片全部裂开** | 站点根目录多套了一层 `部署/` | 根目录要直接是含 `index.html` 的那一层 |
| 图片裂开，但文件名看着正常 | 中文文件名没被正确编码 | 检查 nginx 是否做了 URL 重写或 `charset` 设置 |
| 音频只有 Safari 不能播 | `.ogg` MIME 不对，或 `.mp3` 没传 | 补 `types` 块；确认 `files/` 下 ogg 和 mp3 都在 |
| 页面 404，但文件明明在 | URL 里含 `#`，被浏览器当成锚点 | 站点已做百分号编码（`#` → `%23`），正常访问即可；手工敲 URL 时要写 `%23` |
| 首屏很慢 | 服务器带宽小 | 开 gzip（已配）；或上 CDN；或按第七节砍体积 |
| 403 Forbidden | 目录权限 / 属主不对 | `chown -R www:www`，目录 755 文件 644 |
| 宝塔文件管理器卡死 | 18,451 个文件 | 用 SSH 命令行操作 |
| 上传到一半断了 | 小文件太多 | 用 rsync / WinSCP 续传，或先传 145 MB 的精简集 |

## 九、以后怎么更新

站点是纯静态的，更新 = 重新生成 `部署/` 再覆盖上传。

```powershell
cd "G:\project\其他\game"

# 素材有变动时才需要（图片转 WebP、WAV 转 ogg/mp3、生成缩略图、拷贝视频）
python tools\deploy-assets.py all

# 重建全部页面到 部署\
python tools\deploy.py

# 校验：所有静态引用是否都能在磁盘上找到
python tools\check-deploy.py
```

只想改文案/样式时，跑最后一步 `deploy.py` 就够（约 15 秒），然后重新上传 `html / css / js` 即可，`files/` 不用动。
