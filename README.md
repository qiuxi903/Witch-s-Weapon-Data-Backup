## 二、核心结论速览

### 它是什么

北京水琴铃信息技术有限公司（品牌 WaterBell）开发的**都市幻想轻小说 RPG**，3D 动作 + 卡牌养成，Unity 引擎。制作人齐乐，创始团队 8 人**全部来自宅坛 Stage1st**。官方宣传剧情文本约 30 万字。

### 它的生死线

- 国服 **2018-02-14** 安卓公测 → **2024-08-17 00:00** 关服（2024 年 1 月起已停充值）
- 韩服 2019-02-26 上线 → 2020-04-02 停服 · 日服 2019-04-25 → 2020-08-27 停服 · 港澳台 2019-07-17 → 2020-10-17 停服
- **官方公布的停服原因（原文）**：「由于后续游戏 App 审查条件的收紧，以及公司在游戏研发运营能力的不足。」

### 剧情：一句话与它的结构

> **救国成功的少年第二天从床上醒来，发现自己变成了女孩子。** 这不是搞笑设定，而是圣杯改写因果后留下的永久代价。

- 世界观：**2037 年**近未来。核心概念是「**异质物**（神迹）」——能在特定条件下引发超常物理现象的信息或载体，明确致敬 **SCP 基金会**（XK / EX / Safe 分级、收容基地、模因污染）与**克苏鲁神话**。
- 世界的两支「**原脉**」：**圣杯**代表感性与本能、是魔女的魔力之源；**圣矛**代表理性与秩序、是教团支配「圣女」的工具。
- 主角「怜」成为圣杯容器，获得「触碰羁绊之物即可把魔女从因果的裂缝拉回现世」的能力，被 SID 收编为一线探员。
- **官方主线只有 3 章**（第 4 章起，官方自己把内容全部归入「特殊作战」活动）。最后一节主线内容是「**方舟计划启动！**」——这是一个开局，不是结局。
- **本作没有结局。** 没有终章、没有后日谈、没有小说或设定集。所有最大悬念全部悬空。

剧情结构一览：

| 章 | 种别 | 标题 | 篇幅 |
|---|---|---|---|
| 01 | 主线 | 人生的终结、命运的开始 | 6 节 |
| 02 | 主线 | 想守护的她、被守护的你 | 25 节 + 4 番外 |
| 03 | 主线 | 神魂的治愈·身体的诅咒 | 16 节 + 1 番外 |
| 04 | 活动 | 深潜症 ～Thalassophobia～ | 25 节完结 |
| 05 | 活动 | 创伤反射 | 15 节完结 |
| 06 | 活动 | 黙示録（启示录） | 20 节完结 |
| 07 | 支线 | 少女与皇帝 | 梗概待考 |
| 08 | 活动 | 星塵降臨（星尘降临） | 21 节完结 |
| — | 活动 | 混沌演算 / 死亡告白 | **未完结**（日服从未上线） |

**风格**：性转 + 百合的外壳，包裹政治惊悚、记忆哲学与克苏鲁/SCP 式信息恐怖。玩家的经典概括是：「一章百合悬疑，一章科幻悬疑，一章奇幻惊悚，还有一章 zz 惊悚。」

### 美术：它活下来的理由

- **画风定位**：日系**赛璐璐 / 卡通渲染** + 「**都市时尚 × 学园都市 SF × 暗系色调**」。不是暗黑哥特、不是蒸汽朋克、不是韩系厚涂。
- **配色逻辑**：深蓝灰、暗青、近黑打底，用高饱和的发色与瞳色做视觉焦点。**红色的眼睛**是反复出现的视觉母题。
- **UI**：Live2D 看板娘主界面 + 景深分层 + 科技感 HUD。
- **最稳定的结构性判断**：**「立绘强、3D 模型弱」。** 17173 的原话——「为什么 LOADING 界面图片的可舔度要比游戏中的立绘高上无数倍」，即**企划美术的水准明显高于量产立绘**。
- **美术人员**：台湾画师 **Barabababa** 绘制台服专属羁绊图，Twitter 画师 **@basicyoshi** 绘制三周年贺图，主体美术为水琴铃内部团队。**主美姓名官方从未公开 —— 本档案不作署名。**
- **口碑数据**：TapTap「画面优秀」929 条，仅次于「剧情跌宕」1193 条。

### 音乐与配音

- OST《Witch's Weapon -魔女兵器- O.S.T》，2020-02-14 发行，厂牌 MAGES.，30 首 / 全长 46:34。
- 承制：**Vanguard Sound（中）× INSPION（日）**；中方制作人刘海宜（Eddy Liu）。
- 主题歌《**ANOTHER REAL**》由 **铃木このみ** 演唱。
- 日媒称其 BGM 为「**Persona 风的时髦 BGM**」（爵士/融合 + Funk 律动的都市感）。
- 日配阵容：**钉宫理惠**（怜）、伊藤静、泽城美雪、植田佳奈、能登麻美子、新井里美、石川由依、上坂堇、平野绫、户松遥等。
- **最大的遗憾**：主线剧情基本没有语音（战斗/触摸语音有配音）。

## 四、取材原则（重要）

1. **中文游戏媒体对该作的描述存在整段互相抄袭。** 已逐字比对确认：3DM 2018 年文章的美术段落与 17173 2017 年评测**完全一字不差**；九游 2018 年评测大段照搬触乐 2015 年专访。
   → 因此本档案**不按「媒体家数」计权**，实质独立原始来源只有 **17173（2017）** 与 **触乐（2015）** 两家。
2. **百度百科条目存在明显错误**（把「最新版本」写成 v1.7.1、年份混乱、埃癸斯半径 80 km 与官方 35 km 冲突）。**只作线索使用。**
3. **维基百科与萌娘百科原站在本机网络环境下无法访问正文**，改用 moegirl.icu 镜像与二手转述交叉验证；凡未读到原文的一律标注「待考」。
4. **凡无法交叉验证的细节，均已标注「待考 / 未核实」，不做模糊化处理。**
